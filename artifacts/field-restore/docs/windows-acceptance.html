Field Restore: native Windows acceptance checklist

Candidate: 1.0.0, unsigned, Windows x64. Prepared 2026-10-04. This is a test procedure, not a record of passing tests.

Use a spare machine or separate Windows test account. Back up any existing projects/settings and use disposable copies of audio. Uninstalling removes the installed application and shortcuts; never use irreplaceable files for overwrite tests. Do not disable antivirus or SmartScreen, or upload binaries to third parties. If security policy blocks this unsigned installer, record that result rather than bypassing policy.

1. Prepare and identify the candidate

  1. Record Windows 10 or 11 edition, version/build and x64 architecture from Settings → System → About. Record the test date.
  2. Download Field-Restore-1.0.0-Windows-x64-Setup.exe from the app's Install dialog. Keep these instructions and any earlier installer locally before disconnecting.
  3. In PowerShell, adjust the path below if needed, then compute the hash: 
    $installer = Join-Path $HOME 'Downloads\Field-Restore-1.0.0-Windows-x64-Setup.exe'
Get-FileHash -Algorithm SHA256 -LiteralPath $installer
    Expected SHA-256: 
    450306122cc53387f0bd9a49286813ad4cb38884f9f55379ec86c3def989c142
    Stop if it differs. This candidate has no verified signer, certificate thumbprint or signing timestamp.
  4. Prepare short, playable WAV, RF64 and FLAC test recordings in a folder outside the installation directory. Use a separate export folder. Missing RF64 or FLAC coverage must be marked NOT RUN, not PASS.
  5. Record hashes before testing. Change this path to your test recordings folder: 
    $sources = 'C:\Users\YOUR_TEST_ACCOUNT\Documents\FieldRestoreTest\Sources'
Get-ChildItem -LiteralPath $sources -File |
  Get-FileHash -Algorithm SHA256 |
  Export-Csv -NoTypeInformation -LiteralPath "$HOME\Desktop\field-restore-sources-before.csv"

2. Fresh install and offline launch

  1. Use a test account with no prior Field Restore installation or data. Run the verified candidate installer. Record installer warnings, install destination and whether installation succeeds without administrator elevation.
  2. The default destination is %LOCALAPPDATA%\Programs\Field Restore. Check the desktop and Start menu shortcuts and Windows Installed apps registration.
  3. Close the app completely, disable Wi-Fi and disconnect Ethernet, then launch from an installed shortcut. Confirm the complete interface loads without networking. Keep networking disconnected for the following checks.

3. Offline import, editing, export and source protection

  1. For each WAV, RF64 and FLAC source: import it, play it, apply an audible restoration edit, compare original/processed playback, and export processed WAV audio and a report. Record the actual edit and output paths.
  2. Play each exported WAV in an independent local audio player. Check duration, channels and audible result. Open each report in a local text viewer and confirm it contains the expected recording/edit information.
  3. Using only the disposable WAV source, attempt to export to that exact original filename and path. If Windows asks for overwrite confirmation, proceed only for the disposable file so the application's protection is exercised. Expected: Field Restore rejects overwriting the original. Record the message.
  4. Export under a new filename in the original source folder. Expected: export succeeds and the original remains unchanged.
  5. Recompute and compare source hashes: 
    Get-ChildItem -LiteralPath $sources -File |
  Get-FileHash -Algorithm SHA256 |
  Export-Csv -NoTypeInformation -LiteralPath "$HOME\Desktop\field-restore-sources-after.csv"
Compare-Object `
  (Import-Csv -LiteralPath "$HOME\Desktop\field-restore-sources-before.csv") `
  (Import-Csv -LiteralPath "$HOME\Desktop\field-restore-sources-after.csv") `
  -Property Path,Hash
    Expected: no differences. Keep exported files outside this folder until the new-filename test, then remove only that test export before comparing. Do not remove or rename source files.

4. Persistence and relinking across restarts

  1. Save an editable project with a distinctive title, an edit with recorded parameter values and a changed persistent setting. Record these values. Export a local project backup if available.
  2. Close Field Restore completely. Confirm it is no longer running in Task Manager, then restart while offline. Reopen the saved project and verify title, edits/parameters and settings. Confirm source access works or the app explicitly requests relinking; after relinking the correct original, playback and export must work.
  3. With the app closed, move a disposable source to another folder. Reopen its saved project and check that missing-source handling is explicit rather than silently using different audio. Relink the moved original and confirm edits remain intact.

5. Update from an earlier release

This requires a genuine earlier installed release. Reinstalling 1.0.0 over itself does not verify an update. For a confirmed first release with no released predecessor, record NOT APPLICABLE and the reason. For a later release where an earlier installer exists but is unavailable, record NOT RUN and leave native verification incomplete. The user confirmed that 1.0.0 is the first and only released installer; cross-version updating is not applicable to it.
  1. In a separate test account or resettable spare machine, install the earlier release and record its version and installer hash. Create/save a project and change a persistent setting there. Record title, edit values and source/output hashes.
  2. Close the old app completely. Install the verified 1.0.0 candidate into the same location and under the same Windows account.
  3. Launch offline. Confirm the new version in Installed apps, retained project/settings, working source access or explicit relinking, and successful playback and export. Record any warnings, missing data or duplicate registration/shortcuts.

6. Uninstall and retention

  1. Before uninstalling, save and close the app. Create a uniquely named unrelated text file and a nested folder with another file inside the actual installation directory. Record their full paths and hashes. Do not reuse any shipped filename. Also keep disposable original audio, exports and project backups outside the installation directory.
  2. Uninstall through Windows Installed apps. Confirm shipped application files, the uninstaller, Field Restore shortcuts and Installed apps registration are removed. Confirm the unrelated files and nested folder remain unchanged; the installation folder may legitimately remain because these files are present.
  3. Confirm originals, exported audio/reports and project backups still exist with unchanged hashes. Confirm %APPDATA%\Field Restore remains. Do not manually delete it.
  4. Reinstall the same verified candidate under the same account, launch offline and reopen the saved project. Confirm project edits/settings are retained and playback/export work after any explicit source relink.

For every row, report PASS, FAIL or NOT RUN, with observations. Include screenshots/error text for failures. Redact personal usernames and unrelated file paths. Do not send credentials or private recordings.
